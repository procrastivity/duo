# docs/

Design documentation for duo, organized by topic.

`vnext/` is the exception: the product-normative planning set
(roadmap, contracts, design record, decision series), snapshot from
the retired `terminal-multiplexers` archive at its 2026-09 freeze and
authored here from now on.

Convention: each topic gets a directory, and decisions ratified while
working that topic land in `docs/<topic>/decisions.md` — an append-only
record of what was decided and why, one entry per decision. Supporting
material (rubrics, scenarios, worked examples) sits alongside it in the
same directory.
